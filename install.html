Installing on Windows

When you open the Clipciety or Sinciety COMMAND installer, Windows may show a blue "Windows protected your PC" screen. That's normal for new apps, and here's how to continue.

Why Windows shows it

Windows SmartScreen warns about any program it hasn't seen many people download yet, especially from smaller studios like ours. It doesn't mean Windows found anything wrong with the app. Sinciety apps are built from our own code by our own automated build, and they only accept updates that carry Sinciety's digital signature. The warning goes away as more people install, and when the apps arrive in the Microsoft Store.

How to install

  1. Run the installer you downloaded. If Windows shows the blue screen, click More info.
    Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognised app from starting. Running this app might put your PC at risk.
    More info
    Don't run
  2. Check it's ours, then click Run anyway. The app name shows Clipciety_…_x64-setup.exe or Sinciety COMMAND…setup.exe.
    Windows protected your PC
    App: Clipciety_0.8.20_x64-setup.exe
    Publisher: Unknown publisher
    Run anywayDon't run
  3. That's it. The installer finishes in a few seconds, and the app keeps itself up to date from then on, so you only see this once.

Only install from sinciety.org. Our download links always go through downloads.sinciety.org. If you got an installer anywhere else, delete it and download it again from here.
