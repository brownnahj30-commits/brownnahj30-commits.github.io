DCUOCodex

Search any DC Universe Online character and inspect their Combat Rating, Skill Points and combat stats, with the source and date shown for every number.

Launch Codex ↗ What it does
01 About

Know any character

DCUO Codex reads public character records from Daybreak's official Census service. It never guesses: if a value isn't in the record, it says so.

I

Search

Find characters by name, then narrow it down by server, faction, power, Combat Rating or Skill Points.

II

Inspect

Open a character to see their Combat Rating, Skill Points and combat stats, plus their raw equipment and feat records.

III

Clear sources

Every inspection shows where the data came from and when it was retrieved. Missing values stay marked as missing.
